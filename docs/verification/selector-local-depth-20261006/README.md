# 第一层局部展开选择器改造

基线为 `b56cba83436ebf76208807ab31bb569afb611fb6`。本次只调整第一层与其 CLI 入口，不改变第二层按需读取、负责人提示词、算法或模型参数。

## 用户意图与归档对齐

已阅读 `docs/acceptance/outline-selection-strengthening-20261006` 和 `docs/acceptance/outline-ch5-full-material-20261006` 的 README、用户原话、执行说明及实际结果。

- 用户构想是自主寻找值得投入的局部展开不足；旧四个跨章组和13个单元是模型输出，按章拆分、Ch5合并和Plus访问器组合是本地实现选择。
- 六批选择加强与另一次五单元完整材料直送Max为不同试验。后者输入331,422 tokens，15条段落任务没有变化；不能用它否定此前两单元按需加强。
- 本轮不增加跨章联合编辑或整章重写。第一层默认阅读完整细纲，材料只作辅助；完整读取、核实及修订由原第二层完成。

## 筛选目标

优先筛选影响用户问题、明显值得补足的局部任务：机制解释关系不足；研究比较及其意义未安排；决定结论的条件、反例或限制未入任务；不同问题混装而无法充分展开。允许不选，不设数量配额，不因短、引用少或措辞可润色就选择。

重新阅读原29单元后，补充两类同性质问题：

1. 任务要求较强结论，但未安排建立该结论所需的推理或比较。原Ch1纵向监测任务直接要求优于静态快照，而材料呈现的是多种指标、条件下的关联。这里只提炼“缺少推理台阶”，不把科学纠正答案写入提示词。
2. 同章局部任务重复同一材料、分析和结论，阻碍知识推进。原Ch1两个单元重复同一JCOG案例是观察依据；生产提示词明确重复引用本身不是缺陷，不做风格性去重。

身份错配不是本轮扩展的选择类型；不把选择器变成全面审稿器。

## 实现边界

- 第一层保留每章完整 `chapter_plan`，包括条件、案例用途、段落任务和主张。默认辅助输入仅为细纲实际引用来源的导航；不重新输入全部A/B或工具回答，不裁字符串前缀。
- 可显式启用更详细材料视图作诊断，但默认运行不依赖它。未直接读取完整材料时，选择理由是待第二层核实的缺口假设。
- `selection_reason` 说明任务依据与投入收益；`improvement_focus` 指明局部解释、比较或条件任务；沿用 `selection_context` 原样传到第二层。
- 一个可编辑簇只能来自同章。相邻章可只读。跨章输出及绕过校验的跨章投影明确报错，保存原响应，不静默拆组、不自动付费重选。
- 未选单元、最新只读职责与原材料保留；原第二层仍可不改或拒绝选择器前提。
- 新请求合同更新缓存签名；同输入可恢复，合同或实际输入变化时保留旧尝试而不复用旧选择。

## 本地使用

优先从本地真实的完整章节包构建输入，不能把公开脱敏归档当生产缓存。CLI支持章节包列表、以chapter_id为键的完整包字典，以及新版选择输入。

```text
python scripts/upgrade3/outline_strengthening.py --mode select --input <complete-chapter-payloads.json> --output <new-selection-run> --selection-profile outline_selection --tokenizer <local-qwen-tokenizer.json>
```

默认只prepare并导出实际消息和费用估算。普通运行不需要额外材料目录开关。历史只含身份索引的选择输入缺乏新版导航来源时，应从原完整包重新prepare。

本地真实测试只需检查：模型是否选中必要且高收益的同章局部任务；焦点是否传到原按需Max；最终任务是否更可写并保住有效知识。不需要再做整批模型赛马或人为给出科学修法。

## 离线证据

同目录记录会给出前后实际消息、来源版本及校验结果。所有选择响应均标为受控离线返回，实际消息由生产函数构建；没有调用模型，不能称为真实生成质量测试。公开真实归档的输入体积检查另行标记为脱敏副本派生，不冒充原始wire。


### 实际检查结果

- 专项88通过，其中选择器42项；完整upgrade3为1385通过、12失败、8子测试通过。锁定基线为1355通过、相同12失败、8子测试通过；失败集合逐项一致，详见 TEST_RESULTS.json。
- OFFLINE_MESSAGES.json 保存同一合成任务的旧/新选择器实际消息及下游原访问器、负责人消息；OFFLINE_RESULT.json 给出跨章旧接受/新拒绝、同章可编辑范围、只读边界和焦点传递结果。返回是受控离线数据。
- ARCHIVE_INPUT_CHECK.json 对公开脱敏的7章29单元重新构建只读检查输入：全部chapter_plan逐值相等，默认实际消息正文177,984字符，目录57,563字符，完整章计划89,511字符，199个来源身份导航保留361个回看位置。没有把A/B全文或工具答案塞入第一层；额外科学背景已在完整细纲的案例用途和条件中保留。
- 序列化消息192,577字符；无本地分词器的保守估算约96,288输入tokens，含余量的上下文181,571tokens，低于当前模型容量。3.751716元是思考和回答均用满上限的保守预留，不是本轮实际费用。本地应使用实际分词器重新prepare并核对预算，不为压预留而降低思考容量。
- 第二层outline_on_demand、outline_strengthening、正文规划和quality参数文件与b56cba8逐字节相同。当前CLI改动限于选择入口与参数说明。
- 重建归档检查仅重算公开副本的输入指纹；不修改原归档、不把它用作生产缓存。

运行须知：第一层默认完整细纲＋任务关联来源导航。扩展语义目录只在明确需要时用 `--include-selection-material-index`；它可能显著增大输入。不要把旧实验的该开关机械带入新默认运行。
