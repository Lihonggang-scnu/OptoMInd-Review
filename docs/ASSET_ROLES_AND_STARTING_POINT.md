# 资料分类和新任务起点

这份说明只回答一个实际问题：一次新的研究从哪里开始，哪些文件能当证据。

## 四类资料

| 类别 | 通俗含义 | 能不能直接当论文事实 |
|---|---|---|
| `historical_test_asset` | 第一次试车留下的旧论文和旧结果，例如 `core58` | 不能；只用于回看旧测试 |
| `stable_guidance` | 由优秀综述提炼出的“怎样组织综述、怎样提出问题”的写作手册，即智识库 | 不能；它只教写法和规划 |
| `current_task_material` | 当前问题新找到的论文、正文片段和经过许可的全文 | 可以，但还要通过证据和主题检查 |
| `mutable_run_cache` | 搜索、下载、解析和断点续跑产生的临时资料夹 | 只有在同一个问题、同一套规则下才能复用 |

## 新任务怎么开始

命令行入口默认不再打开 `core58`。它会在本次运行目录创建一个没有论文的空起点，随后由 Semantic Scholar（主要的学术搜索服务）和合法开放获取下载去寻找当前问题的资料。

如果确实要重放第一次测试，必须明确写出 `--base-kb` 并加上 `--allow-historical-test-assets`。这一步会在运行记录中标成历史测试，不会被误认为当前研究资料。

智识库默认文件是：

`outputs/review_example_memory/final_canonical/intellectual_moves_active_by_category.json`

它只进入综述结构设计和科研计划设计，不能进入事实引用、证据判断或论文正文的事实来源列表。

## 如何理解“旧文件没迁移”

如果一个文件在新电脑上不存在，这通常表示“还没有复制过来”或“需要重新下载”，不等于 SQLite（程序使用的本地数据库）内部关系损坏。只有同一个数据库里记录指向不存在的对象，才叫数据库内部的孤立记录。运行记录会把这两种情况分开写。
