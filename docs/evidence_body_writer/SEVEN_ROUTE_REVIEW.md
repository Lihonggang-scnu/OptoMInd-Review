# 七条全文写作路线复核与下一轮决策

本轮目标是把已验收细纲写成有机制深度、比较能力和全文推进的正文，同时把费用控制在值得长期使用的范围。结论：保留连续作者的完整稿作为基线；停止原样重复七条路线。下一步优先降低作者的无效阅读负担，保住已派知识任务，再用自主读者检查全文是否真正讲清楚。默认仍用 Plus。

## 正文到底好在哪里，差在哪里

连续作者已经能建立七章次序，保住一些重要比较，例如不同免疫靶点下的代谢物效应、初治和耐药人群的干预差异，以及主要和次要终点的区别。这说明链路有可用的写作底座。

但独立章节第二章保留了更有解释力的实验区分：谱系追踪、TCR克隆、耗竭实验与人工抗原匹配边界；连续作者把部分内容压成一条顺畅的机制故事。写得顺不等于写得深，下一轮不能为了去重复而删掉这些支撑判断的内容。

三类问题反复出现：

1. **执行说明变成正文。** 第七章出现“详细阐述”“提供临床关联的策划摘要”等说法，可追到细纲 source_uses；第三章也有“规划未来路线”。这些字段应告诉作者做什么，不能直接作为科学叙述。
2. **条件没有持续约束综合。** 同一完整稿一处写小样本伴随关联，另一处写成“因果关联”或“决定性因素”；不同队列、模型或时间锚点在归纳时混在一起。新输入保留完整语义对象和出处，读者层检查这些关系是否真正写出。
3. **同一用途反复展开。** FMT相关疗效、毒性和供体数据跨章重复；合理的同研究复用应推进新的解释，不需要重新报一遍全部数字。仅输入真实前文还不够，因此保留全文读者与有材料的局部编辑候选。

独立读者修后只改变两处文本：收窄表格里过强的FMT结论，以及补足MC38模型背景。改动有用，但还没有解决全文任务口吻、机制压缩和重复。第二批编辑中一个锚点确实存在，另一个不存在且章节认错；应改地址协议，而不是放宽到模糊自动替换。

这些本题例子仅用于本报告和离线重放，不进入新生产提示词，不作为下一轮模型的问题清单。

## 为什么这次要改输入

旧作者把“完整材料”实现为多份包装和快照共同入模。首章107份来源记录中，六类A/B/精读/补充字段的原始值共783,285字符，按同一规范身份及同一字段精确去重后只需430,544字符。另有完整材料、单数/复数补充字段、全文只读任务重复包装。

新的本地编译器不生成科学摘要，也不截600字符：

- 同一身份、同一语义字段、完全相同的值只存一份；不同条件、不同快照保留并明确关联
- 一个发现及其条件作为完整对象，不截半段；工具答案、综述转述、互补材料继续参与
- 当前任务明确需要的来源先进入作者；其它来源仍保存在完整池，可按稳定身份回读
- 当前完整任务与科学材料分开；B中的科学贡献和边界保留，planning_summary标为先前规划解释
- 已知用途/传输字段不反复充当科学正文；未知字段采取保留策略
- 只读全文职责提供组织方向，实际已经写好的前文提供文章状态

完整档案是无损的；默认模型视图是明确、有轨迹的选择。体积变化同时包含精确去重、去包装和任务范围投影，不能统称为“所有内容原样入模”。具体数值见验证记录；字节变小不等于已经证明token容量足够，本地先用实际tokenizer预览即可，不需要付费试错。

## 不超过四个新候选

| 路线 | 实施方式 | 要回答的产品问题 |
|---|---|---|
| packed_whole | 本地编译材料＋完整细纲，一次写全部BODY；超容量则零付费记录 | 去掉冗余以后，一次完整写作是否可行且值得用？ |
| packed_continuous | 同一材料编译器；按自然章节推进，完整当前任务、相关材料与实际前文；一次局部补写 | 保持细节的连续作者能否以更低费用稳定完成全篇？ |
| dossier_author | Plus先自主选择完整证据对象，程序补齐设计/限制/归属；作者读所选原文，可回读；全文可容纳则一次写，否则明确按章推进 | 一个独立供材中间层能否让作者更专注，把机制、比较和条件写得更深？ |
| scoped_revision | 复用完整底稿；全文读者自主找问题；编辑器按块ID和原文哈希修相关段落，按需供材 | 用少数有收益的修改，能否补足作者遗漏而不花钱重写全稿？ |

不为凑四组而付费。packed_whole先免费预览；若仍超限，它只作为容量结果保留。其余三条是本轮主要投入。scoped_revision复用现成完整稿，底稿生成费与编辑增量分别报告。

## 费用和取舍

新增独立60元覆盖全部本轮调用，包括选材、回读、补写、读者、编辑和失败占额。默认Plus；不自动升级Max，也不要求用完预算。建议顺序：免费预览全部入口 → packed_continuous完整稿 → dossier_author完整稿 → 选一份完整稿做scoped_revision；packed_whole如果确实可容纳，可提前做一次低成本整篇尝试。

本地可以根据已生成全文的实际质量调整后续投入，不必为了严格实验设计重复购买同一输入。保留一个未编辑的完整底稿和对应编辑后全文，方便判断改进是否值钱。

评价先核对实施：材料是否正确、是否偷偷变更范围、是否完整七章、是否真实供给条件。再读成文：机制有没有解释、比较是否有意义、条件是否约束判断、重复有没有新用途、后半篇有没有缩水。最终选择按“完整可用稿的总费用＋实际阅读质量”，不按引用数、字数或成功状态排名。
