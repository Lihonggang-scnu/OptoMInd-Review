# 紧凑写作提示与自动状态恢复

## 范围

本轮只调整“指南→正文”。冻结的自动 Max 指南、章节供材与连续写作前文保持；作者、补写和状态恢复均使用 Plus。此处的状态恢复判断内容是否交付，科学质量仍需独立阅读。

## 提示词

- [作者](../../prompts/guided_body_writer/writer.md)：逐句核对来源，保持对象、条件、分母、结果方向；保留实验对照与反例；直接展开问题与比较，精简重复背景和过渡。
- [补写](../../prompts/guided_body_writer/completion.md)：执行同一来源核对原则，以插入方式补齐具体缺口。
- [状态恢复](../../prompts/guided_body_writer/metadata.md)：核对保存正文与章节安排，返回完成状态及具体遗漏。

提示词保持跨领域：研究对象、分组、条件、数值、实验对照等原则可用于不同学科。正文中出现错误，需要区分材料自身的问题与作者重组时新增的问题；写作层按来源的明确事实处理安排中的歧义。

## 自动恢复流程

1. 正常交付：直接接续下一章。
2. 标记大小写、空白、JSON 围栏等可明确解释的格式变化：本地解析，免费恢复。
3. 正文正常传输，但完成状态缺失或存在仅限元数据的错误：至多发起一次 Plus 状态判定。输入保存正文、全文指南与本章安排；原正文原样保留。
4. 有具体缺口：沿用现有的有界补写；有效的未完成声明继续保留。
5. 截断、传输异常、无法确定的返回：保存结果与原因，停止当前依赖链。恢复失败不会触发质量重抽或无限循环。

恢复调用使用原有模型调用、缓存、费用与预算路径。其输出额度不超过 2,048 token，关闭 thinking。配置 `automatic_metadata_recovery` 默认为 `true`，可显式设为 `false`。没有新增账本或资金授权。人工声明接口保留为兼容恢复手段。

## 本地验证边界

先运行免费回归与归档响应回放，验证常见标记变化、缺标记恢复、真实缺表补写、异常传输、缓存重用与预算阻断。使用假客户端返回状态决策；免费回放不能证明 Plus 的真实判断质量。

真实写作质量宜先小范围比较：固定本轮第三章与第六章实际材料和前文，使用新提示词与 Plus 生成候选；检查解释对照、增量论述、对象与分母、语言密度。保持输入一致，才能区分提示词效果。完整七章重跑与引言生成另行决定。实际调用仍计入原写作账本，有效累计上限 58.3609232 元，当前快照余额 25.946408 元；开始前重新核对，独立指南账本不并入。
