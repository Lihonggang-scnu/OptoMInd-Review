# 冻结指南后的正文最小修复（2026-10-09）

本次只改正文作者的两处交付要求、派生交付格式和显式 Plus-only 测试入口。细纲→指南已冻结；现成 Max 指南只是输入，不触发 Max 调用。连续逐章写作、实际前文、材料回读、补写和状态恢复机制保留。

## 实际改动

1. [主写作提示词](../../prompts/guided_body_writer/writer.md)：将“没有固定数量指标”改为“未明确指定时不设固定指标；指南中的明确全文要求应落实”。引用按实际去重身份，不平分到章节，不堆编号，不预支尚未写出的引言。生产提示词没有写死 150；本题的 150 由冻结指南输入。
2. 同一提示词区分“整章外层围栏”与正常代码示例、`guide_writer_metadata` 元数据围栏。补写提示词没有修改。
3. 正式作者按章节边界制作 DELIVERY 副本：只对可明确识别的 Markdown 正文包装去掉外层围栏，再使用已有引用格式器。原始返回、FULL_BODY、段落文本、正常代码块及送给下一章的真实前文保持原样。不确定的包装保持原样并记录诊断。
4. `scripts/upgrade3/guided_body_writer.py --plus-only`：本轮测试必须带此开关，配置预检及每次实际作者/补写调度都只接受 `qwen3.5-plus`；与 `--allow-max` 互斥。其他已有显式实验能力不被删除。

`delivery_format_adaptation` 保存每章原始/格式副本哈希、外层围栏处理和引用身份序列检查。格式通过不是科学引用正确或内容质量通过。
