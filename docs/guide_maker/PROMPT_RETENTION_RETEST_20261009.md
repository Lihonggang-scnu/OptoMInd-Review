# 细纲→指南：内容保留与可执行写法复测

## 这次解决什么

上次真实指南已能指定主讲位置，但出现四类剩余问题：

1. **安排不一致**：全文要求某章只作概念介绍，章内仍有必须保留的设计、对象与结果表。主讲分配也未充分交代其他章节增加什么。
2. **局部建议扩大为统一模板**：要求每段报告同一验证状态、每类对象走同一解释顺序。
3. **内容角色压缩**：独立机制、实验或比较贡献被概括成泛泛的限制提醒，已有来源作用随之变窄。
4. **限定改变**：把“也可能、并非仅有”改成确定或互斥判断。

前版提示已有“不要重复、不要统一模板”等禁止项。此次将具体做法补入原条目，加入一个无领域名词的短示例：区分表格概览、主要解释和后续反例；保留来源的不同作用与原有条件；在同一次生成内协调全文与各章。没有新增规划器、评审器、任务映射、固定补读数或输出字段。

本轮只修改指南提示词，补充一个显式 Max 配置及测试说明。默认 Plus、冻结规划、供材、读取流程、预算执行器和正文作者均不改。配置中的 8 是原有逻辑阶段上限，不是要求调用 8 次，也不是允许独立抽样 8 个版本。

## 相对择优，不追求零缺陷

先看实际输入和完整指南，再参考旧亲审意见。给出少量具体前后例子，评价以下四点：

- 主讲位置、后章增量与原图表/内容责任是否协调。
- 有独立作用的解释、实验、比较、反例及支撑来源是否保住。
- 解释顺序是否随材料而变，比较是否落实设计与适用条件。
- 原有可能性、范围和并存关系是否保留。

允许局部标题、表达、少量可局部修改的重复或组织问题。相对旧版有实质收益且没有明显更严重退步，就可推荐保留，并列出剩余问题；某一处缺陷不自动否决整份指南。若明显更差，保留旧版而不是循环调用直至“完美”。不要把原细纲已有的问题一概归因于指南，也不要以补读次数、指南长度或引用编号数量打分。

结构错误、缺章、截断或来源身份不可解析须与写作品质问题分开记录，草稿不能冒充完整终稿。程序 `complete` 不是语义验收证明。
