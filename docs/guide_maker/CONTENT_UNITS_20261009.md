# 内容保留与连续写作：先指南，后正文

## 本次决定

用户批准有限解冻“细纲→指南”，恢复 2026-10-05 七章、29 个写作单元、173 篇去重文献稿的内容展开能力，并利用指南改善全文组织。上游科学规划不改。提示词简洁不等于正文短；正文篇幅服从解释、比较、反例及条件所需。

旧成功稿仅用于评测对照，不进入生成输入，不复制其科学答案、章节措辞或固定单元数量。复用的是内容传递与连续写作机制；正常冷启动只依赖当前题目的细纲和材料。

本次交付是代码、中文提示词及免费验证。真实模型质量须由本地测试判定。29 是历史样本数量，不是生产规则；本次没有调用付费模型，也没有新增或重置预算。

## 输入与输出

细纲和轻量来源目录 → 模型组织全文与写作单元，按需补读 → 程序将已有具体内容原样装入单元 → Plus 按单元连续写作。

- 指南负责主讲位置、后续增量、详略、比较方式与解释顺序。
- `writing_units` 指定本章连续写作单元；`content_task_ids` 引用输入已有内容身份，用于装入现成内容。模型使用 C0001 等确定性短地址，程序还原为原身份；不会模糊猜测错误地址。
- 具体解释、发展步骤、来源用途、表格行和限定条件由程序传递。作者可将内容合并、拆分成不同段落，不需要逐任务回答或回报完成 ID。
- 这些身份连接用于供材，不生成任务—段落对应报告。
- 作者接收全文组织、本单元组装后的内容、原单元解释背景、完整相关材料和实际已写前文；补写成果也进入下一单元。
- 旧版没有 `writing_units` 的指南继续使用章级入口；新版指南缺少内容安排时，程序保留遗漏内容并明确标记恢复安排。恢复安排不是模型已做好组织的证明。

本轮保持原内容的章归属，模型可在章内重组单元、通过全文安排协调跨章主讲与增量；不迁移原任务到另一章。跨章补充来源继续用明确来源身份供材。

跨领域通用：单元由当前论证关系决定，可以是一条解释链、一组比较或一个争议，不固定章节数、领域术语、解释模板或补读篇数。首次运行不依赖旧稿。

## 本地 Agent：第一阶段，只测试指南

1. 拉取 `lihonggang-dev`，记录实际代码提交。使用新输出目录和原真实 manifest，保持细纲、来源、工具材料和 tokenizer 版本一致。旧结果只做对照。
2. 阅读本文、`prompts/guide_maker/generate.md`和新增测试。先运行指南与连续单元相关免费测试。
3. 使用现有 `scripts/upgrade3/guide_maker.py`，先默认免费预览。真实指南采用 `config/guide_maker/explicit_max.json` 和明确的 `--allow-max`，保留自主补读及现有格式容错；零补读本身不是失败。
4. 真实调用前核对指南单元总数、调用上限、原账本、已付费用、未决占额和有效剩余额度。当前任务没有新拨款，不把 SQLite 的名义上限当作可重新使用额度，不跨账本转用余额。使用用户已授权的测试额度；不明确或不足时先报告。
5. 完整阅读新指南。重点检查主讲与后续增量、比较维度、具体反例和条件是否保留，是否仍出现统一模板；单独报告程序恢复安排的数量与原因。
6. 免费展开七章所有单元输入，确认原有内容和相关材料送达。占位前文只用于供材检查，不能声称真实连续写作已验证。仅有完整 GUIDE 文件和结构通过，也不能声称质量通过。
7. 保存指南、所有实际请求与响应、补读记录、配置、费用和失败/恢复记录。先汇报指南结果，再决定交给作者的候选。不要由指南测试命令隐式启动付费正文。

## 本地 Agent：第二阶段，再测试正文

1. 使用第一阶段选定指南的确切文件和哈希，记录是否含程序恢复的单元。不要混入旧人工 B 或旧 Max 指南，却标成新指南效果。
2. 使用 `scripts/upgrade3/guided_body_writer.py` 和 `config/guided_body_writer/plus_first.json`，真实运行加 `--plus-only`。作者、补写及状态恢复均不得切换 Max。
3. 先免费预览，核对组装内容、来源用途、表格与材料，确认请求容量和输出额度。单元更小不保证总成本更低；先用实际计量估算，再绑定现有有效余额及本轮上限。
4. 按已批准验证范围执行。建议先比较解释密集章和比较密集章：旧成功写作机制与新指南单元机制使用相同材料、Plus 配置和前文条件。若直接运行完整七章，明确记录该选择，不同时启动多路整篇抽样。
5. 本轮后续单元使用本轮实际已写内容，包括插入补写。失败保留原稿，按既有恢复规则处理；未经核对的未知费用不自动重试。
6. 对照 10 月 5 日的 173 篇稿，以及当前 117 篇稿。阅读独立解释、比较、阴性终点、条件、重复与衔接；统计规范化去重文献身份及其实际用途。150 篇以上目标按实际生成内容计算，不预借未写引言，不把格式编号成功视为引用科学正确。
7. 若不如旧机制，保留已证实有效部分，不开启无限审查或付费抽样。归档正文、各单元请求响应、指南和材料哈希、成本及恢复现场。公开分享排除密钥、账本数据库与未授权全文。
