## 两模块联通

在真实材料上使用受控响应，模拟：

1. 从空指南冷启动，提出一个文献和一个工具补充的阅读需求。
2. 取得完整材料包后更新指南，输出既有作者能接受的 GUIDE.json。
3. 将该文件直接交给指南驱动正文作者，按七章录制正文逐章检查实际前文。
4. 两个模块恢复均为零新增调用。

这个联通试验使用人工 A/B 指南作为受控模型返回，使用旧正文作为录制返回，并采用测试计数器。它验证协议和执行，不证明 Qwen 已学会自动选读或生成同等质量指南。相关信息在 REAL_INPUT_CHAIN.json 中明确标注。
