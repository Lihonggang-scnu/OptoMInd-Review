# OptoMind Review 评审测试入口

## 方案一：无需下载的云端成果回放

打开 <https://lihonggang-scnu.github.io/OptoMInd-Review/>。网页直接展示三组真实端到端研究，可以切换研究题目、查看核心指标、以 10× 速度播放运行事件、逐项打开十三个研究阶段，并核验中英文 PDF、引用映射、质量报告、结构审计和出版源文件。该模式不调用模型，不需要密钥，也不会重新执行研究。

## 方案二：下载源码后的统一前端

Windows 用户解压源码后双击仓库根目录的 `START_OPTOMIND.cmd`；Linux 或 macOS 用户执行 `./start_optomind.sh`。浏览器会打开 `http://127.0.0.1:8765/`，静态回放立即可用。

如需提交一个新问题进行真实测试，把项目方私发的 `api_keys` 文件夹放到仓库根目录，保持文件名不变。进入“真实提问”，点击“检查并准备真实运行”。程序会依次核对项目资产、密钥、Python 科研环境、Qwen 模型和学术文献服务；首次运行缺少依赖时会自动创建 `.venv` 并安装。全部检查通过后，问题输入框和运行按钮自动解锁。

“快速真实验证”保留问题理解、文献检索、证据组织、论点形成和成稿主链，跳过图像生成、翻译和 PDF 编译；“完整自主综述”沿用三组正式实验所使用的出版主链，包含全文统筹、双语出版和可视化处理。两种模式的产物都写入独立的 `local_runs` 目录，不会覆盖三组正式回放。

本地服务只监听回环地址，一次只运行一个任务。页面和日志不显示密钥内容；GitHub Pages 只包含已脱敏的精简事件记录与可公开最终成果，不包含真实密钥、下载论文缓存或本机完整运行目录。
