# 本地 Agent：旧分单元写作路线的 Plus 真实测试

## 可直接转发的任务说明

我们调整了策略：暂时将“细纲→写作指南→正文”保留为实验路线，本轮恢复旧版分单元作者，用当前细纲和材料直接生成正文。目标是恢复并评估链路的内容展开能力，不照搬旧稿，也不为保住新架构继续堆提示词。

请拉取 `lihonggang-dev`，阅读 `docs/legacy_unit_writer/README.md`、生效提示词导出和本轮免费验证记录，记录实际源码提交。使用新的输出目录以及当前完整 `FULL_BODY_INPUT.json`。可以复用你已有的当前供材文件；来源不明时，按 `f5103e99c624951ab549a90b443ab090876ca301` 的 `docs/acceptance/guide-content-units-20261010/` 内 parts 清单恢复原输入并核对哈希。不要重新跑细纲、指南或检索；不要把旧正文输入作者。

本轮模型明确为 `qwen3.5-plus`，使用新的独立 **30 元**预算和专用账本。所有付费调用、失败重试都计入这 30 元；原有账本和余额不动。恢复运行沿用同一本轮账本，不换目录重置费用。不得切换 Max，也不要启动额外的整篇对照实验。

先做免费测试和所有单元的实际消息预览。检查本题的 7 章、29 单元、92 个段落任务、3 个表格任务，以及来源用途、原任务细节、条件、工具材料和章节内来源快照确实送达。194 是当前输入直接绑定的规范化来源数量，应通过程序复核；更大的导航/依赖来源集合另列。这些数量是本题的验收对照，不得写进通用生产逻辑。

使用本地已有的 Qwen tokenizer 核对每个请求的输入与输出容量、计费参数和预算。说明本轮主写作不接收实际前文，这与十月五日旧主写作机制一致；全文框架、同章其他单元安排提供上下文。不要误称为新指南路线的实际前文连续写作。

预览无接线问题后，进行一次完整的当前全部单元写作并合稿。按现有断点与原始响应恢复能力处理格式故障，成功单元不重复收费。遇到费用未知、真实容量不足或实质接线错误，保留现场并停下核对；不要自行截断材料、删任务或换模型。允许个别质量缺陷，不进行无限补写或自动审稿循环。

生成后先完整亲读正文，再对照十月五日 173 篇稿和最近 117 篇稿。重点检查：独立解释是否展开、比较与阴性结果是否保留、研究对象与限定条件是否准确、表格是否实际生成、重复与承接如何。逐一展示有代表性的改善和退步，不能只报引用数量。

统计实际正文中的规范化去重文献身份。目标仍是最终正文连同引言超过 150 篇；本轮未生成引言时不提前计入。区分编号排版成功、身份去重正确和科学引用正确。未引用文献按其实际用途分析，不通过追加空引文或复制旧参考文献表达标。

保留完整实际请求、原始响应、单元正文、合稿、配置、输入哈希、账本费用摘要、失败与恢复记录、亲审报告。公开归档至 `lihonggang-dev` 时，排除密钥、账本数据库、未经授权的论文全文和敏感本地信息；区分受测源码提交和归档提交。核对远端文件后停止新增付费调用，交云端复读。

## 命令示例（PowerShell）

把输入、输出、tokenizer 和账本路径替换为本地实际位置。预览和正式执行使用相同的输出目录与参数，便于复核和断点恢复。正式命令中的 `--key-file` 仅在本地现有凭据机制需要时添加，不要复制凭据到测试包。

免费测试：

```powershell
python -m pytest -q tests/test_legacy_unit_route.py tests/test_legacy_unit_route_review.py
```

全单元免费预览：

```powershell
python -X utf8 scripts/upgrade3/legacy_unit_writer.py --input "<当前 FULL_BODY_INPUT.json>" --output-dir "<本轮新输出目录>" --model qwen3.5-plus --budget-limit 30 --ledger "<本轮专用账本.sqlite>" --tokenizer "<现有 tokenizer.json>"
```

核对后正式执行；恢复时重复同一条命令，成功结果依缓存跳过：

```powershell
python -X utf8 scripts/upgrade3/legacy_unit_writer.py --input "<当前 FULL_BODY_INPUT.json>" --output-dir "<同一输出目录>" --model qwen3.5-plus --budget-limit 30 --ledger "<同一本轮专用账本.sqlite>" --tokenizer "<同一 tokenizer.json>" --run
```

默认输出额度为 32768 token，思考额度为 8192 token。它们是单次上限，不是要求模型写满，也不是费用承诺。`--retry-failed` 会授权失败单元的新付费尝试，仅在费用、错误原因和剩余额度核清后使用；不要作为每次恢复的默认参数。
