# 物理／光学：两个对照深案

证据口径：以下为原文观察和据此提出的设计推论，不是期刊规定。页码只指已保存的相应 PDF 版本；各 P/S 编号遵循 records/PHY.md。无科学事实逐条外部认证，也不据样本倒推作者写作顺序。

## 深案一：PHY01，Bound states in the continuum

原文：[MIT 作者稿](https://www.mit.edu/~soljacic/BIC_review-NatRevMat.pdf)。DOI 10.1038/natrevmats.2016.48，2016；所读为 44 页作者稿。完整摘要 p.1；Introduction pp.1–2；V Outlook pp.10–11。正文核对 I、III、IV 和 II 的指定机制段落，以及 Boxes 1–2。

### 1. 摘要给的不是文献清单，而是统一阅读轴

- S1 先给需要解释的反直觉关系：局域状态与可带走能量的连续谱共存。
- S2–S3 用起源和平台跨度说明这个对象不能按单一材料理解。
- S4 才指出综述贡献是物理机制的跨平台解释。
- S5 指定实验、既有应用与未来方向，使读者知道解释将接到什么实践上。

这里的实质价值是分类与机制地图，不是一条新发现，也不是宣称找到了所有 BIC 的唯一原理。该差别在最后一段才变得尤其重要。

### 2. 五段引言是一个逐步收紧的识别过程

P1 把波束缚放回熟悉的频谱规则，再给违反通常规则的对象。P2 并未继续堆研究重要性，而是用 Fig.1 和复频率、泄漏率、Q 值建立识别语言；它还解释为什么散射入射波不能直接激发理想 BIC。P3 才从早期构造走到可实验控制的平台。P4 又收紧定义：扩展结构、固定平行动量和受约束的局域方向缺一不可。最后 P5 将这些已经统一的对象交给三类机制。

因此，如果删除 P2 的技术内容，受损的不是“知识丰富度”而是读者之后判断一个态到底是不是 BIC 的能力。如果将其扩写成几页耦合模推导，又会抢走 II 的责任。这是按功能判断深浅，不能仅以公式存在与否判断越界。

引文也配合这些任务：refs.1–2 给严格定义的数学出处；ref.3 归属历史构造；Box 1 解释几何禁戒与例外，Box 2 解释部分 BIC 的拓扑稳定性。引用的目的不同，不能统称为“背景支持”。

### 3. 三条可回查的首尾—BODY 链

1. 定义的精确性进入应用取舍。
   - 入口：P2 的零辐射与不可直接远场激发。
   - 主体：I 的对称破缺可使原本 BIC 泄漏；IV 的表面发射激光有意破缺对称性来取得输出。IV 还明确指出某些空芯光纤模式只是近似，而非真 BIC。
   - 收束：V P4 由高 Q 提出其他应用，仍须保持理想辐射 Q 与真实器件损耗、耦入耦出的区别。
   - 设计推论：写摘要或结语时不能把“理想辐射 Q 无穷”压成“实验器件完全无损”，也不能把所有应用都包装成理想 BIC。

2. 统一框架没有偷换成统一定理。
   - 摘要：S4 承诺跨平台的机制解释。
   - 入口：P5 给对称／可分离、调参、逆构造三条路线。
   - 主体：I 说明耦合禁戒，II 给干涉取消与参数条件，III 从目标态反推势、跃迁或边界。
   - 收束：V P2 承认未覆盖机制；V P5 反问是否有更普遍概念，并把拓扑说成有希望的候选。
   - 设计推论：结尾的价值可以是更精确的问题，不必制造“全文最终证明了一条统一原理”。

3. 历史起点不等于实验成熟。
   - 入口：P3 保留量子力学的历史起点与光子结构的现实优势。
   - 主体：I–III 区分理论构造与实际观察；III 的势工程明确说明当时尚未实验实现。
   - 收束：V P3 用入口定义批判若干量子报道的归类或证据充分性，并解释控制参数与衰变通道困难。
   - 设计推论：结论不一定只能复述。它可以评价证据；但是这种评价需要明确来源，本篇在结尾直接引用相关报道。给生成器一个不含这些来源的固定 BODY，并不自动授权它仿造同样批判。

### 4. 对“不得重复”和“结尾不得有新内容”的限定

同一个对象在摘要负责独立预览，在引言负责识别，在正文负责分解机制，在展望负责比较适用边界。这种复现有新的阅读用途。真正应避免的是引言再完成 I–III 的详细证据比较，或新结语复写已有展望。

V P2 的未覆盖机制和 P3 的若干批判引证有结尾新增信息。原文观察不能被改写成“结尾所有句子都已在 BODY 证明”。可迁移的判据是论证责任清楚、来源可追溯、推测与观察分开，不是一条绝对内容禁令。

## 深案二：PHY07，Roadmap for Optical Metasurfaces

原文：[Princeton 托管出版 PDF](https://www.cs.princeton.edu/~fheide/papers/roadmap-for-optical-metasurfaces.pdf)；[PMC 原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10971570/)。DOI 10.1021/acsphotonics.3c00457，2024。PDF 页＝印刷页−815。完整全局摘要与两段入口在 PDF pp.1–2；全局结尾在 p.40。完整读取最后产业专题 §17，其他必要专题位置见记录。

### 1. 必须先确定这份作品的整体单位

这是独立署名专题组成的 Roadmap。全局引言不是每个专题的技术入口；全局结论也不是唯一负责未来方向的段落。

摘要五句逐步连接三件事：超表面已经能做什么、研究正在扩散到哪些邻域、产业为什么需要这种小型化功能。末句由这三项推出界定未来方向的编辑目的。它没有承诺一种统一机制，也没有声称进行了系统检索或产生了正式共识。

Introduction P1 以从三维到平面结构的制造路径解释领域何以形成，再连接产业需求。P2 的长路线图不是随机目录：光学功能走向系统、计算与主动器件，再走向新物理、材料、制造和产业。因此，全局入口短而专题入口长并不矛盾。

### 2. 如果只读最后的 Conclusion，会漏掉真正的技术收束

§18 是一段五句：组稿回顾、阶段定调、基础机会、实际应用、邀请讨论。它主要承接编辑者与研究社区之间的关系，技术信息密度明显低于前面的专题尾段。

技术议程至少在本次核对的三个层次存在：

- §7.3（PDF p.16／印刷831）：从 §7.2 的设计／仿真方法直接推出规模、稳健制造、求解速度、网络泛化和训练数据瓶颈。这里的未来方向有具体方法依据。
- §16.2 与 Table 2（p.37／852）：按三种制造路线的成本、基底、结构高度、树脂与模具限制提出方向。表格的职责是维持比较条件，而非装饰。
- §17.2–17.3 与 Table 3（pp.39–40／854–855）：把已有产品、复杂结构的可制造性和一般代工服务连起来，再将阶段目标转为低成本制造生态、产学交流、统一指标三个优先领域。

此外，§11.4、§13.5、§15.5 各有局部收束。既然技术议程已多次完成，§18 再列一遍全部限制反而可能造成重复。

### 3. 一条具体的兑现链

- 摘要 S3–S5：产业对紧凑、可集成、低成本光学部件的需求，使路线图必须同时面向科学和采用。
- Introduction P2：末端明确安排材料、规模制造和产业视角，不能只停在器件功能。
- §16.2：把制造障碍分配到具体工艺，不以一句“仍需规模化”代替比较。
- §17.2：进一步指出复杂设计与通用代工、PDK 和互连条件之间的落差。
- §17.3：用有前提的阶段路线及三项行动方向消化该落差。
- §18：只需再次明确整份 Roadmap 的时间截面与社区讨论用途。

这条链使短全局结尾在此文体中可理解。若把 §16–17 从输入 BODY 中删掉，还照写同样的“迈向应用”收束，就缺失了它成立所依赖的技术和实施层次。

### 4. 此案不能证明的事情

它不能证明普通单作者／单论证综述适合用一段礼仪性结束。也不能证明每项产业预测已兑现：Table 3 的年度是发表时的预期安排，应作为当时议程来读。某些全局措辞具有倡议色彩，不能转成已经验证的科学普遍结论。

本研究完整阅读全局首尾、最后的 §17，并抽查列出的专题尾段；没有把“已检查分布式结构”写成“逐行读完所有专题的每一处展望”。

## 两案对照后可迁移的设计推论

1. 先明确文章的论证单位。BIC 是同一机制问题逐层展开；Roadmap 是多个署名专题在共同目标下协作。
2. 再确定部件承担的阅读任务。前者引言必须使读者会识别对象，结尾可以以该定义评价证据；后者全局首尾负责范围与共同方向，技术议程可以在专题中完成。
3. 查正文有没有兑现，以及在何处兑现。看到结论薄弱，先查既有末节；看到引言技术性强，先查那些技术是否只是阅读判据还是重做主体。
4. 保留不对称性。摘要负责独立预览，引言建立阅读理由和工具，结尾依据已经读过的主体做更高层取舍。无需强迫三个部件具有相同字数、引文数、句序或认识强度。
5. 样本证明写法存在且可解释，不证明它应普遍执行，也不证明某种生成调用顺序更好。
