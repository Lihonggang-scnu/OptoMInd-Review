## Gate

WAITING_APPROVAL. Begin only after explicit approval following WO-02–04.

## Scope

- `optomind_research/runtime/upgrade3/progressive_review_plan.py`: global material/argument assembly, coordinator handoff, and late-material change detection.
- `optomind_research/runtime/upgrade3/chapter_arrangement.py`: explicit unit IDs, source-brief references, split/merge identity, and validation.
- `optomind_research/runtime/upgrade3/review_unit_writer.py`: unit identity and source-brief consumption.
- CLI assembly only where it builds the same global input; do not create a parallel planner.

## Actions

1. Keep `shared_scope` and `review_argument` as different fields. The final coordinator calibrates the initial argument against material, and final plan, packet, arrangement, and writer receive the calibrated argument rather than a scope statement substituted in its place.
2. Keep user question, scope, facets, and global material themes visible to first-level planning through a compact existing input. Do not add a second planner or pass the entire corpus indiscriminately.
3. Preserve the existing effective `late_material_changes` detection. Repair the initial `material_theme_inventory` update and execution ordering so new sources reach the affected coordinator/chapters without reopening whole-chapter rewriting after case attachment.
4. Carry explicit unit/paragraph IDs through reorder, split, and merge. Keep a compatibility path for missing IDs, but never infer a new task identity from position when an explicit relationship exists.

## Quality examples

- Two different global arguments with the same scope reach distinct writer inputs.
- A late material item appears in the relevant coordination input and does not trigger unrelated chapters.
- Reordering preserves source/task identity; split/merge references do not silently reuse another paragraph's cache.
- Case attachment order remains coordinator/owner → formal cases → arrangement → writing.

## Dependencies and record

Use F12 and F16 evidence plus the identity and late-route outputs from WO-04. Record exact argument/scope fields delivered, unit IDs before/after arrangement, affected chapters, and proof that unchanged units retain their prior text. Label unavailable historical replay material `LOCAL_ONLY`.
