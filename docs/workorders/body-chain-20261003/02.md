# WO-02 — Make directed reading tasks independent, truthful, and retryable

## Gate

WAITING_APPROVAL. Begin only after explicit root approval following `READY_FOR_ASTRA_01`.

## Scope

- `optomind_research/runtime/upgrade3/directed_reading.py`: `DirectedReadingStore`, `add_task`, task identity, output-directory allocation, result fulfillment and retry persistence.
- `optomind_research/runtime/upgrade3/progressive_review_plan.py`: the real directed-reading adapter and practical-content classification path.
- `scripts/upgrade3/directed_reading.py`: CLI/adapter contract only where it is the actual entry to the same store; keep runtime and CLI rules aligned.

## Actions

1. Separate paper identity from reading-task identity. A new question or `required_outputs` for the same paper gets an independent task/output location; a fully satisfied equivalent task reuses its result without consuming another independent-paper slot.
2. Align SQLite `add_task` and output-directory rules. Convert a string question into the contract's purpose/required-output fields so it is executable.
3. Require actual answer content for fulfillment. A non-empty question list is not an answer; preserve useful but incomplete results as `partial`.
4. Add one explicit retry path for a result with no actual answer. Bypass that failed result cache and its `RAW_RESPONSE` while retaining the old attempt; do not create an automatic paid retry loop.

## Quality examples

Test, through the real store and reader boundary, equivalent task reuse, a new question, changed required outputs, empty-answer retry, and useful partial retention. Assert that the controlled model/network substitute is called at the intended boundary; an upper-layer fake that returns success is insufficient.

## Dependencies and record

Use F02/F03 evidence from `references/` and any matching advisor fixture. Record task IDs, output directories, cache keys, old result status, retry result, and independent-paper accounting. Mark unsupported local run artifacts `LOCAL_ONLY`.

## Limits and gate

Offline or boundary-substitute checks only; no paid call, full reading run, credential access, or full test suite. Stop after the bounded record and await explicit approval before WO-03.
