# 亲审时的原文复核（未进入实验模型请求）

为避免把材料卡片自身的表述当成金标准，root 另行阅读了两篇实际论文的公开摘要/正文。这些核对发生在三臂细纲生成之后，未输入候选模型，也未手工修正文。

P0289 原文 Results 的 PPI 分层分析明确把较低口腔菌比例组放在比较的第一项，3.15 个月对应低比例，2.04 个月对应高比例；原卡片虽说高比例结局较差，但没有标清数字顺序。仅复制数字而不配组别不能证明科学正确。文章也区分总体显著关联与 PPI 分层的未达显著趋势，不能互换。

原始研究正文：https://pmc.ncbi.nlm.nih.gov/articles/PMC12107420/ （Results，PPI 与口腔菌交互分析，Figure 3F 附近）。

P0585 摘要确实报告 270 例粪便样本、治疗方案相关的 Fusicatenibacter/Butyricicoccus HR 0.56/0.52 和 Prevotellaceae NK3B31 HR 2.33。不能仅因抽象有方案分层就断言 PC 组完全没有效应，更不能将这项 NSCLC 研究引用为 HCC/CRC 反转的依据。摘要可证报告了哪些关联，不能单凭它完成正式交互作用检验或验证全部原文统计模型。

原始研究摘要：https://pubmed.ncbi.nlm.nih.gov/40058642/ 。
