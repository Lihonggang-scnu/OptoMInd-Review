# 细纲修订真实实验：结果与加入系统的建议

## 结论

这次实际测试了细纲修订，再让修改进入真实编排和写作。最值得继续推进的是 **独立审稿 → 现有章节负责人修订**：在这个两单元任务簇中，它消除了相同案例的重复职责，形成了关联图谱与方法学分析的递进，而且改进确实进入正文。建议作为问题任务簇的可选增强，暂不把每章都强制增加两次强模型调用。

**同材料的一次强模型负责人修订也值得保留。** 它费用约为上述路线的一半，第一单元的知识展开很好，但第二单元漏掉了已明确安排的校正任务。此次两阶段配置更均衡；这只是一次局部对照，不能证明两阶段在所有主题上稳定优胜，也不能淘汰其他三条研发假设。

这份结论来自根智能体对四份细纲和八份新写正文的阅读。模型换序评审仅作辅助；其部分评语归属错误，未作为裁判金标准。没有手工修改候选细纲或正文，没有修改冻结生产源码，也没有整篇重跑。

## 内容到底改善在哪里

### 1. 重复案例变成分工，且进入正文

原细纲两个单元都安排同一 JCOG 研究的三个 HR 数值与方案修饰解释。新写对照也实际重复两遍。

R2 将该研究集中在 U1，用于解释治疗方案与标志物泛化的关系；U2 改为用药时间窗、癌种/宿主差异、感染指征与残余偏倚。新正文没有再报第二遍同一试验的 HR，而是增加了不同的解释。这是职责变化，不只是少写几句。

第四臂单调用也做到消除这个重复。因此，**仅消除这类重复本身并不需要两阶段**；两阶段此次的额外收益在于第二单元的分析落实较充分。

### 2. 案例被组织成比较，而非只放在清单里

R2 将纵向黑色素瘤研究与 mCRPC 的稳定轨迹放在同一解释任务中，讨论单次基线信息的局限和情境差异；实际 U1 正文写出了这组比较，而不是只增加来源数。其 U2 保留 HCC 非显著结果、PD-L1 分层、不同地域与暴露时长的差异，没有为顺畅叙述删掉阴性案例。

第四臂 U1 同样保留跨癌种反转、肠型、跨队列验证、菌株及基因层次，知识展开较丰富，并区分了模型内部表现与外部验证。这说明材料充分的一次高质量构思确实有竞争力。

### 3. 细纲看起来改善，不保证文章照做

初次 R1 的 U1 输入已包含 JCOG/菌株及其他新增任务，实际正文却没有展开；完成原因是 stop，不是输出触顶。第四臂的 U2 输入也有完整的第三任务：指示偏倚、暴露定义、多变量校正、纵向补充与宿主对照；新正文只写了部分动态/宿主案例，没有讲清指示偏倚和校正。

根智能体读取实际 `WRITER_REQUEST.json` 的 `source_brief_details` 确认这些任务已送达。第四臂 U2 返回 stop，788 个输出 tokens，低于 4000 上限。因此这是本次消费者未充分完成任务，不能靠“再重跑规划”解释，也不能仅凭 JSON 比较宣布细纲增强已经成功。

R2 的两个单元此次更完整地实现了各自解释任务。这支持继续研发路线 2，但还没有证明其能稳定消除写作遗漏。

## 不能忽略的代价与错误

- 原细纲对照有一张汇总比较表，候选正文没有同类表。不能靠表格数量判完成，但原表提供的快速比较价值没有自动保留下来；R2 的正文推进更好，不等于各个维度都更好。
- 初次 R1 明确因叙述性综述身份将两篇“降格”，违反用户同权决定。该行为作为负面结果记录，不接受为正确选材规则。第四臂及 R2 未作这种显式降权。综述转述的原始研究仍可凭可用内容和引用身份参与，不强制自身 A/B 或全文。
- R1 与 R2 都仍有把观察关联写成机制解释或强修饰结论的情况；R2 还把关联效应量称为混杂幅度。两阶段不是科学错误免疫层。
- P0236 的总体人数与 NSCLC 亚组效应在初次 R1 中混合；P0289 卡片未清楚配对数值和组别，候选继续沿用了这种歧义。材料已送到不保证模型能正确使用，而输入本身有歧义也不能全部算作模型能力问题。原文复核见 `evaluation/ROOT_PRIMARY_SOURCE_CHECK.md`，核对结果未回填候选请求。
- 原细纲对照 U1 新写正文产生数值型引用，但没有合法显式映射。未将其自动认作 P 号、未手改正文。该臂科学内容仍可阅读，引用完整性另行记录，不能靠猜测美化对照。

## 实验校准与评价限制

首先重放了上一轮返回，纠正纯换行被当成功、合理不改被当错误，以及只报告恢复增量费用的问题。旧 C 并未使用强模型、旧实验并未修订细纲；这次实际使用 Max 并改细纲，不能拿旧结论淘汰新路线。

进行了少量全新、无既往对话的换序评审。旧结果评审先两次误认文本无差异；加入程序提取的实际差异并开启思考后再做两次换序。新三臂两次换序均把 R2 排首位，但次序第二、第三互换，且存在把细纲当正文、把不存在的表归给某臂等错误。因此记录原评语和顺序，不把自动评分当最终质量认证。第四臂由根智能体实读比较，未额外调用评审模型。

共同子集有两项局限：抽取按旧编排来源集限定，漏掉最终 PLAN 中不在该集的 P0576 案例；所有臂共用这个子集，不能声称验证了完整原章的所有案例保留。审稿者看到全章 thesis 和轻量其他章节信息，但未看到任务簇外完整单元细纲；对“纵向承诺缺失”的批评只能在局部判断，不能认证整章原来没安排。

一次/两阶段路线各只有有限的一次生成，没有跨领域配套资产留出测试。职责重分配、去旧纲锚定、试写反馈三条没有独立比较，继续保留为假设。

## 建议如何进入系统

优先保留一个有界增强接口：对有真实组织问题的相互关联任务簇，审稿者看全局职责和相关正文/材料 → 现有负责人决定如何修订 → 导出独立候选细纲 → 现有编排、写作试验其是否落实。复用现有负责人，不造第二 planner，不把审稿意见变成必须服从的答案。

一次强负责人修订作为低成本对照/候选继续保留；此次它约 1.83 元，两阶段约 3.44 元。不能因为后者这次更好，就给所有章节统一翻倍调用。下一笔实验应补齐邻近职责上下文，在一个新的问题任务簇复测这两条，并针对已送达却漏写的任务检验一次有依据的反馈，而不是五条路线全排列。

本轮没有向生产链默认接入新模块。当前证据足以认定路线 2 有真实局部价值、值得继续推进，尚不足以冻结为所有主题默认的稳定优化器。
