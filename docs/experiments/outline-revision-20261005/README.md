# Outline revision tournament — public evidence snapshot

This archive is a sanitized, review-oriented copy of the local experiment
`outline_revision_real_tournament_20261005`. The frozen source identity used by
the experiment was commit `43c1c940f85d92fe414590db1820d73d25a96084` from the `lihonggang-dev` source
line. The original run directory is not part of this public copy.

When checked into the repository, this snapshot belongs under
`archive/history/docs/experiments/outline-revision-20261005/`. It is historical
advisor evidence: it does not replace the production runtime, alter the three
remote branches, or turn the archive tree into a production cache. The copied
drivers are source snapshots for review only.

## What the evidence means

The snapshot contains four plans for the same two-unit cluster, the original
control, two primary revisions, and the aligned-owner arm. It also contains
the real local arrangement/writer mappings and settled costs. The conclusions
in the reports are experiment observations, not a scientific certification of
the chapter.

## Public-copy limits

The original model requests included local project material: A/B planning
understanding, selected deep-read and supplement summaries, source-card
metadata, and bounded local passages. The selected artifacts were inspected
for raw full-paper/reading-card-text fields; the observed count was zero.
Request copies are still structurally normalized and scrub local machine paths;
the public copier applies an explicit `[REDACTED_PUBLIC_COPY: ...]` policy to
any raw full-paper/reading-card-text field if one is encountered. Short bounded
passages, project-generated A/B/deep/supplement understanding, paper identities,
and DOI-level metadata are retained where available.

Because request content is redacted, these files are not byte-exact replay
inputs. The manifest records original and public hashes plus redaction counts.
No raw paper PDFs, full-paper files, API keys, authentication headers, access
tokens, signed URLs, or tokenizer files are included. Raw transport response
files and repeated ledger-before/after histories are omitted; parsed returns,
response envelopes, body outputs, call identifiers, and compact cost evidence
are retained.

## Code safety

The copied drivers are static public documentation copies. They contain no
credentials and their machine-local paths are scrubbed. They are not a portable
run recipe: `prepare`/offline inspection is the intended use. Any production
arrangement or writer stage would require a separately configured local
credential and explicit local authorization; this archive performs no model
calls and cannot silently charge an account.
