## 实际匿名换序复评

新上下文 Luna 读取旧 pair-002-0，判断左侧较好。第二个全新子智能体上下文无法创建，因此未声称两个原生独立上下文均完成；另通过两个独立、无对话历史的 Qwen API 请求完成相同模型的换序复评。

首次 Qwen3.5-plus 非思考，两次请求都包含两侧完整正文、细纲及4份实际相关材料，但均错误报告两侧文字完全相同。两份错误判断保留，不能用于质量排名。

唯一一次有界修正：程序用 difflib 列出实际文字差异及邻近上下文，不附带科学答案或旧评价；仍发送两侧全文与同一材料，改用 Qwen3.5-plus 思考模式。两次独立请求分别判断左侧、右侧胜出，解盲后均为同一个旧 C 候选，未观察到本对交换引起的偏好翻转。这个小样本不能证明无顺序偏差，也不能认证旧 C 路线。

root亲审发现，两方向评价都认可因果措辞与模型名称的局部变化，但仍没有充分区分总体显著结果与用药亚组，且对“功能回补”缺乏原始全文验证。评价结果仍是辅助意见，不是金标准。长稿两側差异查找与科学判断应分开，前者可用程序客观定位，不能把漏看差异当作没有改善。

首次思考调用在创建客户端时触发 `thinking_json_unsupported_for_model`，尚未到API。保留现有客户端，关闭 response_format 的 JSON 模式、由提示词请求JSON，随后实际运行；未改生产客户端或丢弃失败记录。
