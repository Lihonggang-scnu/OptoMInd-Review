# 用户意图与本地执行区分

## 用户授权

本轮用户授权将 selector-strengthening 的成功结果与未完成组上传给云端审阅决断，并要求保留可追溯的实际请求、返回、费用与未完成原因。此前同一方案上下文是：由第一层高级模型自主选择值得加强的单元，再交给既有按需 Max 路径；不硬配额，不把 root 后验意见或人工科学答案喂给模型。

## 本地执行

第一层一次真实选择返回 4 个同章逻辑组、5 个单元；随后本地按预算和输入容量分成 4 个二层候选，其中 3 组实际完成，Ch2 组在付费前阻塞。章节分组、Plus access→Max owner、stream transport、稳定 ID 合并和停付费规则是本地工程落实，不能倒写成用户指定的固定分批或模型组合。

## 后验记录

root 的质量复核、局部限制、合并审计和预算判断均是模型返回之后的独立记录，未进入任何后续模型请求。本包没有把 root 具体科学问题、旧候选答案或质量意见作为输入。
