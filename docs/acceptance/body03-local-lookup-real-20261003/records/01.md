## Change and selection rule

`planning_material_triage.read_local_capture` independently searches the original question for its top twelve papers. Those stable identities own the candidate slots. An independent read-focus search may fill only unused slots. A further paper-restricted focus search can contribute complementary passages within the selected identities even when its global top twelve would omit an original anchor. Stable identities are deduplicated, old passages are retained, and original-question hits precede focused hits.

The existing allocator still gives previously unread papers an initial fair share, then revisits deferred intact segments with spare capacity. The combined candidate window remains twelve, and added passage text remains at most 24,000 characters. This phase adds no contexts; all prior contexts are retained. There is still only one expansion judgment. It does not create a query-rewrite/model call, planner, retrieval service or new passage store.

`search(..., bounded_channels=True)` is opt-in for these bounded reads. It keeps one eligible BM25 hit before reranked distinct-section complements without changing paper ranking. Its default is false. Shared ordinary first reads and `progressive_review_plan.build_candidate_navigation` retain the old search selection. Neither score formula nor scientific prompts changed.

Intact oversized segments can still be omitted with existing diagnostics.
