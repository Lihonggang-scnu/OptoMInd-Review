## Implementation and budget

`planning_material_search.search` adds `bounded_channels=False`. Default scoring, paper ranking and one-kind-per-paper passage selection are unchanged. The opt-in path chooses an eligible lexical anchor and distinct-section reranked complements; repeated segment IDs and same-kind section duplicates are excluded. Default callers include ordinary initial reading and candidate navigation. No default shared-search behavior or scientific prompt is altered.

New `nominated_paper_material` returns at most three body/directed passages, one substantive A finding, and one B contribution. Card channels prefer a lexical match, otherwise an existing substantive indexed finding/contribution rather than a scope label. If none of these channels exists, the prior nomination fallback remains. No whole-paper/file reread, original-study-card requirement, external lookup or model call is added.

`prepare_local_reading` keeps all initial passages and original up-to-four contexts unchanged. Each additional eligible nominated paper (at most twelve nominations) can contribute a bounded context: opening at most 400 characters and at most six section labels, each at most 100 characters. Their actual opening-plus-label character count is reserved from the same 24,000-character nomination allowance before passage allocation. Extra contexts are only attached for nominees that actually supplied material. No-card body passages and cards-only summaries remain usable. Existing omission/status diagnostics remain; nominations are not forced fulfilled.

The existing allocator deduplicates supplied text and expands intact local sections only when they fit its per-hit/remaining allowance; otherwise it keeps the intact selected segment. Over-budget material can still be omitted. Reserved capacity for a context whose passage fails may be unused rather than reallocating indefinitely.
