## 第一轮应检验的能力

先准备约三个固定问题，不运行自主审稿的全组合。问题是待检查的诊断，而不是正确答案；不预写 replacement_text，也不规定必须改。

2. 章节推进：挑跨章同一试验的使用，提供准确的对照块和章级职责。先判是否同用途重复；不同用途的复用允许保留。不能预设删掉重复论文就是成功。
3. 保留对照：挑一个已有具体条件与阴性结果的段落。让方案核查一个可能不成立的问题，观察能否不改；若修改，要看具体知识是否仍在。不能只统计补丁数。
