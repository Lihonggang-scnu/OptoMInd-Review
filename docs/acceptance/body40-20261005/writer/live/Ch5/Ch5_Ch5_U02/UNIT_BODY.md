# FMT在ICI耐药人群中的疗效局限性与生物学屏障

尽管粪菌移植（FMT）在初治人群中展现出恢复免疫检查点抑制剂（ICI）敏感性的潜力，但在高度经治的耐药实体瘤队列中，其作为挽救性治疗的临床活性受到严重限制。MITRIC试验是一项针对ICI耐药晚期实体瘤患者的单臂IIa期篮子试验，纳入了12名在转移性阶段对ICI治疗进展的患者（涵盖黑色素瘤、头颈部鳞癌、肾细胞癌及微卫星不稳定性高胰腺癌），使用ICI长期响应者作为供体进行重复FMT干预。结果显示，该方案安全性良好，但未能观察到客观肿瘤反应，全队列的客观缓解率（ORR）为0%，中位无进展生存期（PFS）仅为1.5个月[ P0578 ]。在全部受试者中，仅1名患者获得了协议定义的临床获益（疾病稳定超过6个月），其余患者均出现疾病进展或短暂稳定[ P0578 ]。这一阴性结果明确提示，在未加选择的高度经治和快速进展人群中，FMT联合ICI难以实现有效的疾病控制，其疗效可能受限于弥漫性疾病剥夺了微生物重塑所需的时间窗口。

这种临床疗效的缺失并非偶然，而是受到微生物定植动力学与宿主固有免疫抑制微环境的双重制约。从生态药理学视角来看，FMT在难治性人群中的失败揭示了“土壤”质量对“种子”存活的关键影响[ P0178 ]。机制分析表明，首次FMT后大多数受体的微生物组仅向供体方向发生短暂的偏移，这种相似性在后续时间点大多下降；唯有那唯一获得长期疾病稳定的患者实现了持久的供体-受体微生物定植，这暗示持久整合可能是产生临床获益的前提[ P0578 ]。更为关键的是，基线时的系统性免疫景观构成了难以逾越的屏障：MITRIC试验发现，基线时髓系偏倚环境（高CD14+单核细胞）和高血清白细胞介素-8（IL-8）水平与较差的预后显著相关[ P0578 ]。治疗后，CD14+单核细胞和血清IL-8水平进一步升高，且这些变化与较短的PFS和OS相关[ P0578 ]。这表明FMT未能逆转由宿主基础疾病状态决定的髓系主导免疫抑制环境，甚至可能伴随髓系驱动的免疫抑制增加[ P0578 ]。相比之下，既往阳性研究（如Davar等）中响应者表现为外周血活化T细胞特征增强及IL-8降低[ P0578 ]，而难治人群的阴性结果则凸显了当宿主处于高髓系浸润和炎症状态时，单纯添加外源菌群难以克服已建立的获得性耐药[ P0474 ][ P0304 ]。

除了MITRIC试验的完全阴性结果外，其他前瞻性研究也证实了FMT在抗PD-1耐药实体瘤中整体响应率极低的趋势。Kim等人开展的一项针对抗PD-1抑制剂耐药的不可切除或转移性实体瘤（主要为上消化道癌症）的单臂研究中，FMT联合抗PD-1治疗的客观缓解率（ORR）仅为7.7%（1/13），疾病控制率（DCR）为46.2%[ P0594 ]。虽然该研究样本量较小且缺乏随机对照设计，但其低ORR数据进一步支持了FMT难以普遍克服已建立的广泛实体瘤获得性耐药的结论[ P0594 ]。综合来看，难治人群的阴性结果并非否定微生物调节的理论价值，而是揭示了临床转化的现实约束：快速生长的疾病背景与宿主基线髓系抑制共同构成了FMT起效的生物学壁垒，亟需通过精准分层筛选出具有特定免疫表型（如高分化T细胞环境）的亚群以改善疗效[ P0578 ]。
