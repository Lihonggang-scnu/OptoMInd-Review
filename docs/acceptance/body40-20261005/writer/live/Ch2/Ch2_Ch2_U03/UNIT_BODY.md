# 髓系细胞重编程与肠道屏障完整性：免疫抑制网络构建与细菌易位机制

肠道微生物组不仅通过代谢产物调节全身免疫状态，更直接参与肿瘤微环境（TME）中髓系细胞的表型重塑，从而构建或解除免疫抑制网络。在实体瘤中，髓源性抑制细胞（MDSCs）和肿瘤相关巨噬细胞（TAMs）是维持“冷”肿瘤表型的关键效应者。微生物信号通过模式识别受体（PRRs）等途径影响这些细胞的极化方向：特定共生菌群的缺失或病原菌的富集可促进MDSCs的募集与活化，并诱导TAMs向分泌IL-10和TGF-β的M2样抗炎表型转化，进而抑制CD8+ T细胞的杀伤功能[362]。例如，某些致病菌可通过局部微环境调控抑制自然杀伤（NK）细胞活性并招募MDSCs，而有益共生菌则倾向于促进树突状细胞成熟及T细胞浸润[438]。在临床干预层面，粪便微生物移植（FMT）被证实能够通过增加肠道微生物多样性并富集有益菌群（如双歧杆菌、普拉梭菌），显著降低TME中MDSCs和调节性T细胞（Tregs）的比例，同时增强CD8+ T细胞的浸润，从而逆转免疫抑制状态并提升ICI疗效[573]。尽管部分机制证据源自血液系统恶性肿瘤模型，但其揭示的微生物-免疫调节轴（特别是短链脂肪酸介导的Treg分化与MDSC调控）为理解实体瘤中的髓系重编程提供了重要的类比参考[539]。

肠道屏障完整性的维持与受控的细菌易位是连接局部肠道信号与全身抗肿瘤免疫的物理基础。响应者与不响应者的微生物组差异首先体现在对上皮屏障的影响上：利用集成蠕动功能的肠-on-a-chip模型发现，ICI治疗响应者的粪便提取物富含鞭毛蛋白相关基因，能通过激活TLR-5信号通路促进IL-1β释放，从而维持ZO-1和E-cadherin等紧密连接蛋白的表达及屏障稳态；相反，非响应者的粪便中高丰度的脂多糖（LPS）合成基因则导致屏障通透性增加和促炎反应[0073]。在此基础上，免疫检查点阻断疗法（ICT）并非单纯依赖屏障渗漏，而是主动诱导特定的内源性肠道细菌（如粪肠球菌、约氏乳杆菌）发生物理易位。机制研究表明，ICT诱导肠道炎症激活树突状细胞（DCs），DCs依赖CCR7信号将细菌转运至肠系膜淋巴结（MLN）及远端肿瘤组织；这一过程伴随MLN的结构重塑（淋巴管生成和高内皮微静脉扩张），使得细菌突破“黏膜防火墙”扩散至次级淋巴器官，进而激活DC并促进效应CD8+ T细胞的产生[166]。在小鼠模型中，这种易位是ICT发挥远端抗肿瘤效应的必要条件，抗生素清除肠道菌群可阻断该过程并削弱疗效[166]。然而，人类队列中的证据多基于观察性关联，例如血清标志物（如sMAdCAM-1）的变化反映了屏障损伤程度，而FMT在人类中更多表现为病原体清除和屏障恢复的宏观效果[573]。此外，细菌易位具有双重效应：一方面，易位细菌可激活肿瘤内巨噬细胞的PRRs信号，诱导其向免疫抑制表型转化（如在胰腺导管腺癌模型中）[0084]；另一方面，特定菌株（如*Paraclostridium bifermentans*）表现出活菌破坏上皮屏障致结肠炎，而其分泌的低分子量代谢物（< 3 kDa）却能增强ICI疗效的独特“双重角色”，揭示了微生物组分在毒性管理与疗效增强间的精细平衡[284]。
