# 交云端独立审读：哪些改动实际改善细纲→正文

## 用户目标与本次纠偏

用户要的是可自主完成新领域任务、写出优质综述的通用产品链路。不能由本地Agent先指出本题科学问题、提供正确答案或手写好段落，再把模型照做算成链路能力。旧稿只用于事后比较。

用户明确指出：恢复是基础功能，不应当被包装成主要成果；频繁掉链子本身反映设计问题。用户更关心解决知识展开、比较、条件、全文组织和表达质量，要求给出直接的判断与下一步解决办法。请把这一要求作为本次审读重点。

## 实际实施与结果

本地保留原分单元Plus作者及完整任务/材料，增加可选的自主任务核查、一次补写和复核，随后调用现有全文局部编辑器。没有重跑规划，没有加入人工科学纠错清单，也没有把单次Max上探正文拼入Plus整稿。

正式源码：`73f938e40ec6c46947d5cca34ad0eee542631107`。主要入口 `scripts/upgrade3/legacy_unit_writer.py`；实现 `legacy_unit_route.py`、`unit_realization.py`、`article_text_editor.py`、`review_unit_writer.py`。各阶段实际执行版本及补丁见 SOURCE_AND_RUN_HISTORY.json。

实际新生成七章29单元。原作者160个规范化引用身份、2表；质量稿和编辑候选187个身份、3表。请用正文中的知识变化判断质量，篇数只用于覆盖核对。

有价值的变化：

- 原只写UBA6机制的单元，自主补回临床33/22个月及对照方案、干预剂量、T细胞外在路径和人类局部暴露未测边界。
- 原只写第一段的安全性单元，自主补回解耦/纵向证据、供体聚类、不同免疫方案及伴随用药，并补回比较表。
- 核查自主纠正NIC组内关联被写成组间比较、总体HR被错用到NSCLC亚组，以及正文/表格中肌苷与腺苷不一致等问题。
- 气候留出自主拆开ALD数字所属实验和比较口径，并补入未直接测甲烷通量的边界；电池留出保住工况和理论容量分母。32份主实验/留出作者请求使用相同系统提示词。

实际反例：

- 药代/测量单元已写三项任务，核查仍因缺一个列举引用判partial，补出重复段落。
- TACITO/Kim历史任务与材料身份冲突仍带入正文；菌丰度阈值方向和DMBT1用途被Plus核查误放。
- 某些补写引入更强的比较和因果断言。覆盖变全与科学判断变好不是同一件事，请分别检查。
- 全文编辑10处修改（5标题、2重复回指、2承接、1术语）有局部收益，但FMT/MITRIC跨章分工仍不充分。其“安全性良好”概括也比原观察范围更宽。

## 本地负责人的直接判断，供你裁决

1. 保留原分单元Plus作者。它能展开具体机制、条件和案例，是目前最有价值的基础。其提示词没有为当前科学题目定制。
2. 自主核查/补写值得保留，但目前不宜全量默认开启。漏任务修复有明确收益，误判补写和科学误放也是真实损耗。
3. 当前核查步骤的成本过高：作者3.600328元，质量步骤7.5674028元，全文编辑0.1047848元。整份新稿共11.2725156元。下一步最有收益的方向，我倾向于自主决定哪些任务值得核查/补写，结合任务与材料身份冲突诊断，而非继续增加同类复核次数。
4. 全文编辑成本低，值得保留为可选整理步骤；它目前处理的是局部标题、重复和承接，不能承担完整论证重分工。
5. 此版比原作者稿更完整，也纠正了一部分条件；全文组织与科学可靠性仍需改善。恢复和预算实现作为基础接线记录，不作为质量成果卖点。

这些是本地判断，请依据实际输入输出支持、调整或否定，不必沿用我的方案。尤其请判断：核查的净收益是否足以保留；如何减少误判和反复输长材料；哪些组织问题应由细纲、写作包、作者或全文编辑承担；下一笔开发成本应优先投入哪里。请给出可实施的建议、理由及代表性证据，避免只列风险或泛泛要求提高质量。
