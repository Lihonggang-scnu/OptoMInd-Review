## 对通用链路的建议

优先保留三个能力：充分的实际模型容量；条件/论证关系/相邻职责随任务交接；按需对有问题的任务簇使用强模型。下一笔研发最值得投入“任务已送达但写作未展开、比较尺度错置、职责重复”的消费诊断，再由有真实材料的编辑定点解决。

本轮带材料编辑是独立实验接线，尚未将其强制变成每个单元的默认步骤。当前证据支持这条局部路线有实际收益，不需要继续重跑全部BODY或同时比较所有候选；独立审稿后负责人再次修订仅在细纲本身仍有职责冲突时触发。
