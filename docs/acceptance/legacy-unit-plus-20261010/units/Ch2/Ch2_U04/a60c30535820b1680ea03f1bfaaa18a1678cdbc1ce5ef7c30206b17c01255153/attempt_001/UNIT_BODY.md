肠道微生物组调节 ICI 疗效的机制并非普适，而是表现出显著的肿瘤类型特异性。在黑色素瘤中，证据主要指向微生物抗原与肿瘤新抗原之间的交叉反应性 T 细胞启动，以及特定微生物分子结构（如六酰化 LPS）对先天免疫的激活 [P0146][P0573]。相比之下，非小细胞肺癌（NSCLC）的机制更侧重于局部代谢微环境的重塑，下呼吸道微生物组独立于肠道菌群，通过脂质与氨基酸代谢途径调节肿瘤浸润淋巴细胞的功能 [P0352]。消化道肿瘤（如 HCC、CRC）则对肠道屏障完整性与细菌易位更为敏感，且微生物景观受肿瘤病因（病毒性 vs 代谢性）的强烈修饰，例如 HBV 相关 HCC 与 NASH 相关 HCC 的菌群特征及免疫响应存在显著差异 [P0113][P0457]。这种异质性在肾细胞癌（RCC）和三阴性乳腺癌（TNBC）中进一步得到印证：RCC 患者围治疗期抗生素暴露显著降低 ORR 与 PFS（HR 1.96-3.10），提示菌群依赖性较强 [P0090]；而 TNBC 中化疗与 ICI 对菌群的扰动方向不同（破坏 vs 恢复），且特定代谢物（如 TMAO）通过诱导焦亡增强疗效 [P0057]。值得注意的是，既往治疗史可重塑菌群 - 疗效关系，如在经恩杂鲁胺预处理的前列腺癌（mCRPC）队列中，*Akkermansia muciniphila* 丰度与疗效呈负相关，这与黑色素瘤中的正向关联形成反例，挑战了跨癌种通用预测模型的适用性 [P0270]。此外，肿瘤内驻留微生物群（非肠道）通过抗原呈递、Th1 极化及基质重塑调节局部免疫，其效应具有空间结构特征且依赖于肿瘤背景，进一步增加了机制的复杂性 [P0535][P0457]。

机制证据的强度与来源系统密切相关，需严格区分临床前因果发现与人类观察性关联。小鼠模型通过 CRISPR 敲除、抗体耗竭及 FMT 功能回补实验，确立了特定菌群（如 SFB、双歧杆菌）与 ICI 疗效之间的因果链条，并解析了下游代谢物（如 SCFAs、肌苷）与免疫通路（如 STING、TLR）的分子机制 [P0146][P0573]。然而，人类队列证据主要基于宏基因组测序与临床结局的相关性分析，或单细胞表型、血清标志物的观察性关联，缺乏直接的干预性因果验证 [P0535]。这种模型系统差异导致机制外推存在风险：动物实验中验证的代谢物浓度与免疫细胞互作在人体肿瘤微环境中可能因药代动力学或免疫背景不同而失效。例如，FMT 联合 ICI 在难治性黑色素瘤患者中的临床试验显示供体聚类与疗效相关，但具体机制通路在人体内尚未完全复现临床前模型的精确度 [P0573]。因此，在解读微生物调节机制时，必须明确证据边界：临床前数据提供机制假设与因果原理，而人类数据提供临床相关性与转化线索，两者互补但不可直接等同 [P0146]。
