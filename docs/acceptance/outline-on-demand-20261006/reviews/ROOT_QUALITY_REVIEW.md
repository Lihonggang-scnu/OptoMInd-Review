# 自主按需供材：根智能体亲审与采用意见

本次评价记录不进入模型请求。测试复用原研究问题、两个关联单元、同章其他单元职责、原局部正文及真实材料，没有提供人工科学问题、修改答案、Max 候选或前一轮评价。输入材料是本地既有记录，不重新检索或精读。BODY 与写作层未改。

## 采用意见

保留“Plus 自主访问规划 → 本地取得原记录 → Max 联合修订”作为低成本加强候选，建议接入显式可选路径。本轮亲读的任务展开总体接近整池 Max，功能层比较更明确，且总费用下降约18%。保留整池 Max 路线作为对照和材料广泛复杂时的可选路径，不把此次10条初选固定成今后任何任务的配额。

直接将同请求换为 Plus 的严格实验只花0.387294元，但内容仍未接近 Max。便宜不是问题，未能充分组织材料才是问题；其结构校验因 P0576 失败不代替内容评价。详见 strict Plus 的 ROOT_STRICT_MODEL_REVIEW.md。

## 真实运行

1. Plus access 读取原任务、正文和覆盖全部材料通道的目录，只输出访问位置，费用0.046572元。
2. 程序按模型指定取得10条完整原记录，包括身份、条件、补充等；具体字段路径当前作为访问焦点记录，仍读取整条记录，未宣称已经按句裁剪。
3. Max 收到当前计划、邻近职责、完整可回看目录及上述原记录，独立修订两单元；费用2.159832元。返回 updated，已有负责人校验与编排投影通过。
4. Max 本次没有要求额外阅读，因此没有第二次 Max 调用。追加读取与旧材料并存由离线测试覆盖，实际模型主动调用续读的效果本次尚未观察到。

目录并非纯身份清单：包含来自原 A/B、精读、补充及本地片段的短摘录（每字段上限600字符，标明截断），它们本身也是实际输入内容。不得说 Max 只看过10篇论文，也不得说所有未初选来源都完全没进入请求。未初选完整记录不进入消息，目录短摘录和原任务仍可参与理解。材料资格不要求原始研究有自身 A/B 或全文，综述转述的可用内容与明确身份仍保留。
