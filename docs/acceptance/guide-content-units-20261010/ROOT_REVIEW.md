## 完整亲读：保住了什么，哪里还不够

先读实际输入与新版两次完整草稿，再读上一轮Max恢复版（GUIDE_RECOVERED_FOR_REVIEW），最后作比较。旧指南没有writing_units，主要是全篇与章级建议；新版增加了具体写作范围与内容连接，这是实用改进。以下意见仅为运行后的评价，没有回填生成输入。

1. **主讲位置和后章增量具体。** 新版将FMT-LUMINate分别用于Ch1证据阶梯、Ch2伴随机制、Ch5初治干预、Ch6供体毒性；MITRIC在Ch1为阴性概览，在Ch5为难治人群主讲；Ch2屏障单元明确“屏障状态→主动易位→髓系后果→人类情境”。这些安排比只有章级口号更能让作者执行。不过旧版已经有很具体的主讲分工，本轮主要增加了单元落位，不能说所有组织质量都提升了。

2. **原知识和比较内容没有被压薄。** 例如Ch2保留独立先天识别、适应性免疫、屏障易位、模型差异；Ch3保留不同分子机制与浓度条件；Ch5保留初治信号及MITRIC阴性；三个明确表格内容地址均送达。这是构造器逐值对照结果，未仅凭目录里存在来源ID下结论。

3. **仍有模板化和指令口吻。** 新版Ch2要求“每个机制节点都按动物因果证据→人类关联/伴随证据→外推限制组织”；Ch3“统一采用分子靶点→证据层级→情境依赖→浓度/递送缺口”；Ch4“每类因素按效应量与时间窗→微生物机制假说→癌种/宿主修饰→因果边界与临床建议组织”。旧版全篇明确要求不得用同一模板套所有对象。新版虽然单元有具体内容，仍额外规定了章内统一顺序。证据区分本身有用，但不宜变成每段都必须走完的固定路数。

4. **重复的主讲声明和实际保留任务仍有张力。** Ch5章级说毒性细节主要留Ch6；其安全单元又要求比较单药/双药毒性发生率、起病时间和供体Cluster B。Ch6再次要求这些比较。单凭“主讲在Ch6”未把Ch5的简要边界与Ch6新增分析分清。保留所有原任务避免漏件，但保留和重新分工还需协调。这是写作组织问题，不能只删除同论文引用解决。

5. **不要把旧细纲错误错算成指南新增。** Ch4的“术前/术后”时间锚点和Ch2的“检查点语气”已在原任务里；本轮指南沿用了它们。没有手工修科学文字。另一方面，新版又把TME浓度、Phase III、非结肠炎样本不足集中为补读问题，仍容易围绕少数缺口组织，未显示针对每类材料的充分不同展开。

实际第二请求同时含11份materials、prior_guide和原reading_needs，而read_history为空；程序在收到本次有效响应后才把该批次加入history。模型必须从当前materials识别已供材，不能只看read_history。空history是否促成重复请求需要云端结合实际消息判断，不能直接断言是唯一原因。当前防重复保护避免了第三次重复花钱，保护应保留；仅把重复需求删掉再标complete会伪造模型完成状态，不采用。

建议云端优先检查这一通用接缝：当前已供材料与历史阅读状态如何清楚呈现；已有材料不足以确认全领域最新证据时，如何回到有界的写作决定，而非反复要求同一记录证明材料库之外的事实。另协调主讲声明与原保留任务，避免固定模板。保留目录、内容地址、作者完整供材与身份修复，无须重新跑规划或给模型人工科学答案。
