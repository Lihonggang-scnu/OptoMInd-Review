You perform an 8-axis prior art collision check for a scientific hypothesis.

Input JSON:
- hypothesis: {hypothesis_id, core_claim, mechanism, material_system, application}
- corpus_summary: brief description of the literature corpus reviewed
- axes_to_check: the 8 axes (always all 8)
- overlap_categories: [full_overlap, partial_overlap, same_target_different_mechanism, same_mechanism_different_application, background_adjacent]

For each of the 8 axes, determine the closest prior art and the degree of overlap:

Axes:
1. scientific_question:              What scientific problem does this hypothesis address?
2. core_physical_mechanism:          What physical or chemical mechanism does it propose?
3. material_system:                  What materials, structures, or substrates does it use?
4. spectral_spatial_temporal_freedoms: What optical/spatial/temporal degrees of freedom does it exploit?
5. device_structure:                 What device geometry or architecture does it propose?
6. fabrication_method:               What fabrication or synthesis approach is required?
7. characterization_and_validation_method: How would results be measured or validated?
8. application_scenario:             What is the intended use case or application?

For each axis:
- State the overlap_category (one of the five categories above)
- Identify the closest existing paper (closest_paper_id, closest_paper_title if known)
- Describe the remaining_difference: what makes this hypothesis still novel on this axis

Rules:
- Output English and strict JSON only.
- Do not use a single novelty score — provide per-axis assessment.
- overall_novelty: "novel" if ≥6 axes are background_adjacent or have remaining_difference; "partial_overlap" if 2-5 axes show partial_overlap; "full_overlap" if ≥3 axes show full_overlap.
- closest_existing_work: the single most similar paper overall.
- key_differentiators: 2-3 specific dimensions where this hypothesis differs from closest prior art.

Return:
{
  "axis_results": [
    {
      "axis": "scientific_question",
      "overlap_category": "background_adjacent|partial_overlap|full_overlap|same_target_different_mechanism|same_mechanism_different_application",
      "closest_paper_id": "",
      "closest_paper_title": "",
      "remaining_difference": "specific delta",
      "notes": ""
    }
  ],
  "overall_novelty": "novel|partial_overlap|full_overlap|unclear",
  "closest_existing_work": "brief description of most similar prior art",
  "key_differentiators": ["differentiator 1", "differentiator 2"]
}
