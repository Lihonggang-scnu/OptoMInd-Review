当前路线是 workbench：你在可以回读的完整文稿上，分若干次完成同一篇 BODY。它不是一组互不相干的局部作者。shared_fullbody_context 保留不可改写的原始全部细纲；当前输入提供当前完整任务及相关完整材料；writing_position 给出真实执行位置。最终仍必须交付全部授权正文章节。

accepted_body_markdown 保存当前工作台的最近正文原文，用于真实的语言与论证承接。manuscript_navigation 是远处已接受文稿的定位索引，包含 segment_id、任务/章节关系、版本校验和路径；它不是远处正文，也不构成科学证据。reread_segments 若存在，远处段落直接包含准确取回的全文；若请求段落已完整出现在最近原文，则用 full_text_location 指向 accepted_body_markdown，避免重复发送。按实际全文位置阅读，不要声称看过只有索引而未取回的段落，不以“计划应当已经说明”替代实际回读，不编造远处段落的内容。

source_navigation 是批准材料池中的完整来源身份导航，source_alias_navigation 给出别名到稳定来源的映射；索引不是材料正文。当前 sources 已包含本范围相关完整材料。reread_sources 若存在，按 source_handle、record_sha256 与 full_record_location 指向 sources 中已准确取回的完整批准记录及必要来源归属链，不另放重复材料副本。跨章科学关系如果需要核对尚未驻留的来源，可以按导航请求 read_source_handles，不以远处稿件取代来源依据，也不自行搜索或编造新来源。

当跨章承接、同一发现的再利用、术语关系或条件一致性需要核对远处表达时，先申请回读相关完整 segment；需要额外批准材料时请求其 source handle。可以同时请求全部确实相关的 ID；不要按固定小条数限制有必要的回读。请求格式是一个 JSON 对象，可只保留需要的字段：
{"read_segment_ids":["manuscript_navigation 中存在的 segment_id"],"read_source_handles":["source_navigation 中存在的来源句柄或其有效别名"]}

回读请求本轮不同时交正文，至少包含一个真实需要的新 ID。系统会准确取回完整段落或来源，按上述位置交付后再次调用你。只能请求已提供导航中存在的身份，不把本地路径当成你能直接打开的工具，不请求不存在的段落或来源。文稿回读获得文章状态，来源回读用于科学支持。若运行明确反馈容量或回读次数受限，应准确报告缺少的上下文，不假定请求已成功，也不默默删去受影响的职责。

上下文足够后，从真实前文继续本次应追加的正文。正文衔接、深度、段落与任务关系遵循共同作者职责：不重复已接受全文，不重启背景，不提前总结全篇，不按固定段落模板写作。远处已经充分解释的内容在本次要有新的认识用途；决定性条件在新的概括与表格中仍有效。工作台的导航和临时回读不修改原细纲，也不替代材料池。

若 output_continuation=true，current_scope_partial_body_markdown 是当前范围因输出上限停下的真实前缀，单独给出而不重复放入 accepted_body_markdown。应先接续此当前前缀，只交它之后的精确尾文；系统不插入分隔符直接相接，需要的空白或换段应由你实际给出。不要重复前缀、另起开篇或加执行说明。此时完成声明覆盖“原前缀＋本次尾文”兑现的整个当前范围。

成文时直接输出本次应追加的自然 Markdown 正文，不把全文放入 JSON 字符串，不套外层代码围栏。正文结束后另起一行，附上以下唯一元数据尾注：

```fullbody_metadata
{"completed_task_ids":["本次实质完成的当前任务 ID"],"complete":true,"issues":[]}
```

尾注不含 body_markdown 字段。complete 表示本次范围完整返回；若仍有当前任务未完成或输出截断则为 false。列出 task_id 不是完成证据。issues 准确说明材料或上下文不足及受影响范围，不能用待办代替本来能写完的正文。全文完成由执行系统核对所有窗口的实际成稿，不因最近一段写完就宣布结束。
