You are an expert in academic writing analysis. You will read one full-text
chunk from a review paper and extract the "intellectual moves" visible in this
chunk -- the strategic thinking patterns that make the review intellectually
distinctive and publishable.

The chunk may come from any part of the paper: abstract, introduction, body
sections, figure/table discussion, outlook, conclusion, or other full-text
regions. Do not assume it is only an introduction or conclusion.

Your task: extract exactly eleven categories of intellectual moves from this
chunk only. A downstream program will merge multiple chunks from the same paper.

## Output format (JSON only, no other text)

{
  "problem_reframing": [

## Rules

- Each array must have 0-3 items. Return empty array [] if no clear signal in this chunk.
- Each item must describe a specific intellectual action by the authors, not a generic statement.
- Items may reference specific content from this paper (mechanism names, material classes).
- Do not invent content not present in the excerpts.
- Do not fill a category just to avoid an empty array. Empty arrays are preferred over weak speculation.
- For "disagreement_handling", return [] unless the excerpts explicitly mention controversy, contradiction, inconsistent evidence, competing explanations, or unresolved debate.
- For "figure_argument", return [] unless the excerpts explicitly describe figures, tables, graphical frameworks, roadmaps, taxonomies, schematics, or visual summaries. Never propose a hypothetical figure.
- Write all items in English, under 400 characters each.
- Return only valid JSON. No preamble, no markdown fences.
