Run the reusable, budgeted OptoMind Research Harness.

options:
  -h, --help            show this help message and exit
  --question QUESTION
  --question-file QUESTION_FILE
                        Read one UTF-8 natural-language question from a file.
  --query-plan QUERY_PLAN
  --delivery-start {history,plan,body}
                        Delivery branch: import an existing written manuscript
                        (history) or run the frozen planning_revision chain
                        with recorded responses (plan), or write the current
                        complete outline/material input (body) through the
                        resumable unit route. body preview is offline; --run
                        uses the explicit owned ledger.
  --delivery-manifest DELIVERY_MANIFEST
                        history: written-run manifest; body: current fullbody
                        manifest of ordered arrangements and packet roots
  --delivery-batch-root DELIVERY_BATCH_ROOT
                        history start: batch root with BATCH_JOBS/front/back
                        matter
  --delivery-packet DELIVERY_PACKET
                        plan start: writer packet to deliver
  --delivery-recordings DELIVERY_RECORDINGS
                        plan start: recorded responses JSON for offline replay
  --delivery-input DELIVERY_INPUT
                        body start: current complete lossless
                        FULL_BODY_INPUT.json
  --body-version {baseline,chapter_coherence}
                        baseline preserves saved requests; chapter_coherence
                        adds actual full-outline duties and substantive-gap
                        checks
  --model {qwen3.5-plus}
  --output-tokens OUTPUT_TOKENS
  --thinking-budget THINKING_BUDGET
  --budget-limit BUDGET_LIMIT
                        Absolute lifetime CNY cap of this separate experiment,
                        never an increment
  --ledger LEDGER       Explicit dedicated SQLite ledger, required with --run;
                        reuse for all resumes
  --account-ledger ACCOUNT_LEDGER
                        Optional second SQLite ledger shared by physical calls
                        across projects; reuse its path
  --account-budget-limit ACCOUNT_BUDGET_LIMIT
                        Immutable account lifetime CNY cap; required only for
                        a new account ledger
  --account-mapping-dir ACCOUNT_MAPPING_DIR
                        Persistent dual-reservation receipt directory;
                        defaults beside the account ledger; reuse on resume
  --budget-scope BUDGET_SCOPE
                        Explicit experiment identity shared across input
                        subsets and holdout books; immutable for this ledger
  --reconcile-receipt RECONCILE_RECEIPT
                        Audit and settle an existing open hold from a local
                        JSON receipt; no provider calls
  --run                 Explicitly allow live provider calls
  --retry-failed        With --run, permit an explicit new writer attempt or
                        one recorded quality failure retry without replayable
                        output; retain prior attempts and ledger holds
  --quality-control, --no-quality-control
                        Independent Plus actual-body assessment, at most one
                        bounded correction/completion and post-check; original
                        writer output retained
  --reparse-saved       Explicitly reparse saved quality RAW without rebuying
                        attempted stages; unfinished stages require --run and
                        the same owned ledger
  --article-edit, --no-article-edit
                        One resumable Plus whole-article local edit after
                        full-book writing/quality completes; selected subsets
                        explicitly skip
  --only-unit CHAPTER:UNIT
                        Repeatable pilot selection; retains full book/material
                        context and reusable writer request identities
  --key-file KEY_FILE   Local credential file; not read in preview, never
                        copied
  --key-index KEY_INDEX
                        Select exactly this 1-based candidate in --key-file,
                        without environment priority or key fallback
  --tokenizer TOKENIZER
                        Existing local tokenizer.json, no downloads
  --delivery-config DELIVERY_CONFIG
                        Offline delivery config JSON (schema
                        review_v2_delivery.config.v1): research question,
                        language, chapter roles, edit/front-back fixture or
                        recording paths, identity catalogs, figure assets,
                        cross-reference moves, compile_pdf. Without it the
                        history/plan stop after assembly (assembly_only), body
                        after selected BODY editing/numbering; with it the
                        unified downstream 02��03��04��05 runs. Paths resolve
                        relative to the config file.
  --delivery-out DELIVERY_OUT
                        delivery output root
  --execution-profile {library_offline,private_study,submission}
  --base-kb BASE_KB     Explicit test/recovery paper database override. Normal
                        runs omit this option and project relevant material
                        from the central long-term cache before external
                        retrieval.
  --long-term-material-cache-root LONG_TERM_MATERIAL_CACHE_ROOT
                        Stable central MaterialUnit cache. Normal runs search
                        its CURRENT snapshot before any external retrieval.
  --no-long-term-material-cache-writeback
                        Diagnostic/test-only: do not merge newly materialized
                        text back into the central long-term cache.
  --allow-historical-test-assets
                        Permit an explicitly supplied core58 database for
                        historical pipeline tests. It remains disabled for
                        normal research.
  --m1-library M1_LIBRARY
  --phase3-artifacts-root PHASE3_ARTIFACTS_ROOT
                        Phase-3 run directory whose audited material drives R4
                        authoring.
  --output-root OUTPUT_ROOT
  --qwen-key-file QWEN_KEY_FILE
                        Use only keys from this file for the run. Historical
                        project, desktop, and environment key pools are
                        excluded.
  --run-dir RUN_DIR     Resume or continue an existing harness run directory.
  --rebuild-scoped-kb   Explicit recovery only: archive validated topic-scoped
                        KB/S2 artifacts and rebuild them. Production resume
                        reuses validated manifests by default.
  --rebuild-phase3-handoff
                        Explicit recovery only: archive an existing Phase-3
                        directory and regenerate the canonical R3 handoff.
  --auto-confirm-query-plan
                        Continue without the normal human review of a newly
                        generated plan.
  --mock-query-planner  Use the deterministic Query Planner fallback; for
                        offline checks only.

  --no-phase3-llm-dag   Explicitly disable the optional cross-section LLM
