usage: quickstart.py [-h] {doctor,help,run,resume,replay} ...

OptoMind Review local research pipeline

positional arguments:
  {doctor,help,run,resume,replay}
    doctor              check the local environment without paying for a call
    help                show this public command guide
    run                 run the research harness with the remaining arguments
    resume              resume a research harness run with the remaining
                        arguments
    replay              open the read-only replay when replay assets are
                        present

options:
  -h, --help            show this help message and exit
exit_code=0
