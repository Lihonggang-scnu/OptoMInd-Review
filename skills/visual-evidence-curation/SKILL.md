# Visual evidence curation

1. Read the article map and actual section argument.
2. Inspect only canonical candidates for that section.
3. Select a small non-redundant set with explicit argumentative purposes.
4. If a consequential need is still unserved, classify at most a small number
   of relevant pending OA visuals and inspect the section again.
5. Never generate quantitative scientific evidence.
6. Record missing needs without penalizing valid prose.
7. Validate paths, provenance, and disclosures before completion.
